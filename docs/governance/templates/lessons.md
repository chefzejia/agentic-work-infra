# Lessons from Work

记录失败证据和候选规则。候选经人审议后进入所属规则真源；本文件保留证据和引用。

## 记录与审议

- 新证据能说明规则缺口、执行错误或适用范围问题时记录，不按周制造条目。
- 同一问题重复三次触发审议，单次严重问题也可审议；次数不自动决定晋升。
- 审议核对根因、严重程度、反例、适用范围和维护成本。同一事件在多个文件出现，只算一次。
- 通用改进反馈到标准真源，项目和模块约束更新其所属文档。采用的 STANDARDS 副本只有显式升级时更新。
- 晋升后保留正式规则引用，不在 LESSONS 中继续维护第二份正文。无需建空分类。

- 审议结果：<结论、理由及正式规则位置，有则保留>
